## 指标定义

- 增益：1 Hz 处 `20log10(|V(out)-V(ym)|)`；
- 0 dB 频率：增益第一次从大于 0 dB 向下穿越 0 dB 的频率；
- 相位裕度：`180° + phase(UGF)`；
- 输出共模表中记录 `out` 的 DC 值，零差模输入时两端对称；
- 电源电流：`-I(VDD:p)`。
